# ☕ Coffee Shop Website

A simple and responsive Coffee Shop website built using HTML, CSS, and JavaScript. The website provides a modern user interface where visitors can explore featured coffee drinks, view prices, and contact the coffee shop through an interactive contact form.

## 🚀 Features

* Responsive and clean design
* Navigation menu for easy browsing
* Hero section with featured coffee image
* Drinks menu with images and pricing
* Contact form with client-side validation
* JavaScript-powered form submission feedback
* Organized project structure with separate CSS and JavaScript files

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
Coffee-Shop/
│
├── index.html
├── style.css
├── app.js
└── README.md
```

## 📸 Website Sections

### Home

A welcoming hero section introducing the coffee shop and its offerings.

### Menu

Displays a selection of coffee drinks with images and prices.

### Contact

Allows visitors to submit their name, email, and message through a contact form.

* JavaScript DOM manipulation

* Project organization using separate files

## ⚡ Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/coffee-shop.git
```

2. Navigate to the project folder:

```bash
cd coffee-shop
```

3. Open `index.html` in your browser.

No additional installation or dependencies are required.
